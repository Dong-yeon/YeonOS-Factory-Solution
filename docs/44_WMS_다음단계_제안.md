## 0. 요약

- WMS 2부(B1~B7) 중 남은 구현 몫은 **PDA 입고 하나**이고, 그것도 사용자 `LotService` 작업 뒤로 보류돼 있다(12.12.9).
- 나머지 "나중" 항목은 셋으로 나뉜다: **다른 모듈·사용자 결정 대기**(손댈 수 없음), **WMS 혼자 할 수 있는 작은 것**, **설계부터 필요한 큰 것**.
- **추천 순서**: ① 대사 결과를 홈 카드·알림으로(b) → ② 입고 가능 위치 공개 메서드(Q5) → ③ 출고 예약 설계 문서 → ④ 부족 투입 대기열은 MES 와 설계 합의 뒤.

## 4. 추천 순서와 이유

1. **S1+S3 대사 홈 카드** — 이미 만든 대사(V184 포함)가 지금은 사람 눈에 안 띈다. 작고, B3 에서 만든 검출이 실제로 쓰이게 한다. 마이그레이션 없음.
2. **S2 입고 가능 위치** — MES 화면 체감이 크고 계약 1개. MES 세션이 받아 줄지 확인 필요.
3. **L1 출고 예약 설계 문서** — 구현 전에 "정말 필요한가"를 데모 흐름으로 먼저 가린다.
4. L2 는 MES 일정에 맞춰, L3 은 APS 요청이 오면.
