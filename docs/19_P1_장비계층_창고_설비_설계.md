## 1. 결론 먼저

- **"어디"는 한 그루 트리** — ISA-95 장비 계층(공장 › 구역 › 라인 › 셀)과 창고(저장 구역 › 로케이션)를 같은 `mst_equip_hier` 에 둔다. ISA-95 도 저장 구역(Storage Zone)·저장 단위(Storage Unit)를 장비 계층의 한 갈래로 본다[1][2]. 재고(P4)·실적(P2)·설비 상태(P5)가 같은 노드 id 를 참조하고, 경로(`P1/WELD/L2/C3`)는 나중 UNS 토픽과 같다(docs/02 2.2).
- Enterprise = 회사(`comp_cd`), Site = 공장(`sys_plant`, P0 에 이미 있음)으로 대응하고 트리에는 넣지 않는다(docs/02 보완안 그대로).
- **설비(4b)는 트리 노드가 아니라 노드에 붙는 인스턴스** — ISA-95 Work Unit(Unit·Work Cell) 수준의 "기계 한 대"는 클래스(용접기·사출기)·자산 번호·설치 위치를 가진 별도 테이블. 트리를 깊게 만들지 않는다.
- **물리 자산(4b)** = 금형·지그·게이지 실물(시리얼). 어느 설비에 언제 설치됐는지는 **원장**(설치·해체 사건 행, 정정은 역분개, 같은 자산 두 곳 동시 설치 금지 = 배제 제약).
- 진행: **4a 공장·장비 계층·창고/로케이션 → 4b 설비·설비 클래스·물리 자산·설치 이력.**

## 2. 장비 계층 노드 유형과 부모 규칙

| 유형 | ISA-95 | 예 | 부모로 올 수 있는 유형 |
|---|---|---|---|
| `AREA` 구역 | Area | 차체동, 프레스동 | (공장 바로 아래) |
| `LINE` 라인 | Work Center — Production Line / Process Cell | 용접 2라인 | AREA |
| `CELL` 셀 | Work Unit — Work Cell | 스폿 셀 3 | LINE |
| `WH` 창고 | Work Center — Storage Zone | 원자재 창고, 완제품 창고 | (공장 바로 아래), AREA |
| `LOC` 로케이션 | Work Unit — Storage Unit | 랙 A-01, 선반 A-01-03 | WH, LOC(랙 › 선반 › 칸 중첩) |

- 부모 규칙은 DB 트리거가 최종 판정(직접 SQL 포함). 셀 아래·라인 아래 창고 같은 조합은 막는다 — 라인 옆 자재 대기장은 "라인이 속한 구역 아래 WH" 로 둔다[추정 — 현장 라인사이드 창고 관행].
- 코드는 **공장 안에서 유일**(로케이션 바코드 스캔 한 번으로 찾게). 회사 안에서는 공장마다 같은 코드 허용.
- 이동(부모 변경) 허용 — 단 자기 자신·자기 하위 아래로는 금지(순환), 다른 공장 부모 금지, 부모 규칙.
- 삭제 없음 = 사용 중지. 하위에 사용 중인 노드가 있으면 사용 중지 거부(고아 방지). 사용 중지 노드 아래에 새 노드 추가 금지.
- 깊이 상한: LOC 중첩 포함 전체 10단(정책 아님, 상수) [추정 — 랙·선반·칸 3단이면 충분].

## 4. 화면

| 화면 | 구성 |
|---|---|
| **공장 관리** `mst-plant` (4a) | 목록 + 상세(코드·이름·주소·시간대·순서·사용) |
| **장비 계층·창고** `mst-equip-hier` (4a) | 공장 선택 → 왼쪽 트리(hb.tree, 유형 배지, 펼침·접기·키보드) / 오른쪽 노드 폼(상위·유형·코드·이름·순서·사용). "하위 추가"는 선택한 노드를 상위로, 유형은 부모 규칙에 맞는 것만 |

| 물리 자산 `mst-asset` (4b) | 목록 + 설치 이력(원장) + 설치·해체 동작 |

## 4b 상세 (2026-10-19)

- **설비 클래스** `mst_equip_class`: 회사별 코드·이름(용접기·프레스·사출기…). 클래스 속성은 7단계.
- **설비** `mst_equip`: 코드(회사 안 유일 — 설비는 공장을 옮겨도 같은 자산), 이름, 클래스, 공장, **설치 위치 = LINE·CELL 노드**(비우면 보관·미설치), 제조사·모델·시리얼·자산 번호·설치일. 트리거: 위치는 같은 회사·같은 공장·LINE/CELL·사용 중, 클래스는 같은 회사·사용 중.
- **물리 자산** `mst_phys_asset`: 금형 MOLD·지그 JIG·게이지 GAUGE, 코드·이름·시리얼, 대상 품목(선택), 금형 수명 타수, 게이지 교정 주기(일)·최근 교정일.
- **설치 이력** `mst_asset_install` — 원장 규약의 변형(근거: 설치는 "언제부터 언제까지"라 끝이 나중에 정해진다):
  - 행 = 설치 구간 [installed_at, removed_at). **UPDATE 는 두 가지만**: 열린 구간을 해체로 한 번 닫기(removed_at null → 값, ≥ 설치 시각), 잘못 넣은 행 무효(void_yn N → Y + 사유). 그 밖의 수정·DELETE 금지(트리거·권한).
  - **같은 자산 두 곳 동시 설치 금지** = 배제 제약 `EXCLUDE (comp_cd =, asset_id =, tstzrange(installed_at, removed_at) &&) WHERE void_yn = 'N'`.
  - 다른 설비로 옮기려면 해체 후 설치(서비스가 "지금 설치 중" 이면 `ASSET_INSTALLED` 로 알림). 미래 시각 설치·해체 금지, recorded_at = 기록 시각(occurred 와 별도).
- 화면: 설비 관리 `mst-equip`(목록 + 상세, 위치 = 계층 경로 선택, 클래스 관리 대화상자), 물리 자산 `mst-asset`(목록 + 상세 + 설치 이력 표 · 설치·해체·무효).
