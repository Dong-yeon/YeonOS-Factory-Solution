### 2.2 QU-2 재현 절차 (WMS 실사)

1. 실사 신규(공장 P1, 범위 RM-WH, 순환 실사) → [시작] → 줄 추가 2개(위치 RM-A01-01, 품목 TIP-M6-1.2·WIRE-ER70S-1.2).
2. 목록에서 그 실사를 골라 센 수량 칸에 7·3 입력(저장 안 함).
3. 다른 실사 행 클릭 → **대화상자 없음**, 상세가 바뀜. 다시 원래 실사로 → 센 수량 칸 `["",""]`.
4. 다시 9 입력 → 다른 화면 주소로 이동 → `beforeunload` 경고 없음. DB 센 수량 `[null, null]`.

- 고칠 방향(WMS 판단): 센 수량 칸을 `hb.dirty.mark`(또는 줄 영역에 `hb.dirty.watch`) + 그리드 `beforeSelect: leaveOk`, [수량 저장] 성공 때 `hb.dirty.clear`. 조회는 지금처럼 목록만 다시 읽어 입력이 남는다(확인함).
