# S2 회사별 격리 RLS — "앱이 실수해도 DB 가 막는다"

> 2026-10-22 · 관련: docs/01(P0 플랫폼 설계), CLAUDE.md 아키텍처 핵심 · 걸린 시간: __분

**상황 한 줄**: 한 DB 에 여러 회사(A사·B사) 데이터가 같이 있다. SQL Server 프로젝트였다면 모든 쿼리에 `WHERE comp_cd = ?` 를 붙이고 빠뜨리지 않기를 바랐을 것이다. 이 저장소는 그 조건을 **PostgreSQL 이 모든 쿼리에 자동으로** 붙인다.

## 0. 먼저 예측 (코드 보기 전, 3줄)

> 개발자가 매퍼 XML 에서 `comp_cd` 조건을 깜빡했다. 그 화면에서 B사 사용자가 A사 데이터를 볼 수 있을까? 막는다면 어디서, 어떻게 막아야 할까?
