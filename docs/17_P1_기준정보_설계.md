## 1. 범위와 단계

00 6장 P1 범위: 품목·BOM·라우팅(REV, 파라미터 세트, 표준 사이클타임)·공정·장비 계층(ISA-95)·설비·물리 자산(금형·지그)·창고/로케이션·거래처·특성 마스터(`qms_char`)·외부 ID 매핑·클래스 속성(jsonb), 엑셀 업로드(미리보기→실행).

순서 원칙: **참조되는 것 먼저**(07 4.1 로드 순서와 같게) + 매 단계가 화면·API·테스트까지 끝난 상태로 커밋.

| 단계 | 범위 | 첫 화면 | 완료 기준 |
|---|---|---|---|

- 공통코드 API 는 `attrs` 를 함께 내려준다(하위 호환: 필드 추가). 화면 `data-unit-from` 은 단위가 붙은 수량이 생기는 3단계(BOM 소요량)에서.

### 3.3 API (01 5.7 규약 그대로)

### 3.5 이상 사용 (테스트로)

A사로 B사 품목 조회·수정·사용 중지·엑셀 / B사가 추가한 단위를 A사 품목에 지정 / 순질량 `1e3`·`-1`·`0`·`0.0000001`·`NaN`·문자열 / 정렬·페이지 파라미터 조작 / 와일드카드 검색 / 같은 멱등키 두 번 / 조회 권한만 / 품목코드 `a-1`(대문자 정리) 과 `A-1` 중복 / `<script>` 이름(그대로 글자로 저장·표시).

### 3.6 `ColumnSpec` 확장 (15 R6)

- `priority`(1 항상 보임 · 2 · 3, 기본 2), `minWidth`(px, 기본 = min(폭, 60)), `flex`(남는 폭을 받는 열).
- hb.grid: **넓을 때** = flex 열에만 남는 폭을 폭 비율로 나눈다(flex 열이 없으면 지금처럼 전체 비례). 나머지 열은 정의 폭 그대로 — 울트라와이드에서 코드 열이 300px 로 늘어나는 것 방지(15 5.3).
- **좁을 때** = 가로 스크롤(지금) + 그리드 메뉴 **"열 맞춤"**: priority 3 → 2 순서로 보이는 폭에 맞을 때까지 숨긴다(1 은 숨기지 않음). 다시 누르면 원래대로. 바닥줄에 "열 n개 숨김". 화면 설정 저장에는 남기지 않는다(기기마다 폭이 다름).
- 열 폭 드래그 하한 = `minWidth`.
- 거래처관리: 코드·명 = 1(명 flex), 구분·사용·전화 = 2, 대표자·사업자번호·담당자 수·수정 일시·수정자 = 3(15 4.6 표).

## 3b. 2단계 상세 — 엑셀 올리기(이관 엔진, 07 D1)

### 흐름

```
템플릿 내려받기 ─▶ 올리기(파일 + 모드) ─▶ [같은 요청] 읽기(SAX) → 헤더 매핑 → 행 정규화·검증 → 파일 내 중복 → DB 대비 → 스테이징 저장
                                                                                                   │
            ┌────────────────────────── 미리보기(건수 NEW/CHANGE/SAME/ERROR, 행 목록, 오류 엑셀) ◀────┘
            ▼
         실행(오류 0건 또는 "오류 행 제외") ─▶ [한 트랜잭션] 상태 VALIDATED→DONE 조건부 + 반영 + 대사 결과
```

### 구성

| 구성 | 내용 |
|---|---|
| 템플릿 | **Java 빈 `ImportTemplate`**(코드·버전·대상 화면·열 정의·검증·반영). 07 4.5 의 `sys_excel_template` 테이블 안 대신 — 열 정의와 검증 규칙이 코드 한 곳에 있어야 버전이 어긋나지 않는다(결정 P1-8). 첫 템플릿 `MST_CUST`·`MST_ITEM` |
| 템플릿 파일 | 시트 1 데이터(헤더 = 사용자 언어 열 이름, 필수 `*`) + 시트 2 안내(열 설명·필수·허용값·예시) + 숨김 시트 `_meta`(템플릿 코드·버전). **`_meta` 가 없거나 다른 템플릿·버전이면 거부** |
| 헤더 | 위치가 아니라 **이름으로** 매핑(한국어·영어 열 이름, 필수 표시 `*` 무시). 필수 열이 없으면 거부, 모르는 열(`comp_cd`·`회사` 포함)은 **무시하고 목록으로 알림** — 회사는 로그인 회사로만 |
| 셀 | SAX(`XSSFReader`) 스트리밍. 숫자 셀은 **셀 서식 무시하고 저장된 값**(서식이 소수 1자리여도 4.85 그대로), 수식은 계산된 값, 앞뒤 공백·전각 공백 정리. 코드 열은 코드 또는 이름(한국어·영어) |
| 테이블 | `sys_import_job`(회사별 RLS, 감사): 템플릿·버전·모드·상태(`VALIDATED`/`DONE`/`CANCELED`)·건수·원본 파일(`sys_file`)·대사 결과 jsonb·`row_ver` / `sys_import_row`(회사별 RLS, 감사 예외 — 본 테이블 반영이 감사됨): 행 번호·상태·업무 키·정규화 값 jsonb·오류 jsonb·기존 행 id·row_ver |
| 행 상태 | `ERROR`(형식·코드·파일 내 중복·`INSERT_ONLY` 인데 이미 있음) / `NEW` / `CHANGE`(값이 다름) / `SAME` |
| 모드 | `INSERT_ONLY`(기본 — 새 것만) / `UPSERT`(새 것 + 변경). 파일에 없는 열은 바꾸지 않는다(빈 칸은 "지움" — 열이 있으면) |
| 실행 | 한 트랜잭션: `update … set status='DONE' where status='VALIDATED' and row_ver=?`(두 번 눌러도 1건만) → NEW insert · CHANGE update(**검증 때 본 row_ver** 와 다르면 전체 롤백 409 `IMPORT_STALE`, 다시 올리기) · SAME·제외 오류는 건너뜀 → 대사(파일 행 = NEW+CHANGE+SAME+ERROR, 본 테이블 건수 전후 차 = 넣은 수) |
| 권한 | 대상 화면 기준: 템플릿·미리보기 = SEARCH, 올리기·실행·취소 = SAVE. 작업은 **올린 사람만** 본다(같은 회사 다른 사람 404) |
| 상한 | 정책 `IMPORT_MAX_ROWS`(기본 50,000), 파일 크기 `FILE_MAX_MB`, 압축 해제 상한(zip bomb) |

## 9. 품목코드 = 시스템 코드 + ERP·고객 품번 매핑 (2026-11-09, 기준정보 하위 세션 `claude/master-item-code`, V238·임시 V9950)

사용자: "품목코드는 key-in 이면 안 되지 않을까", "ERP 품목코드가 있고 system 품목코드가 있으면 되지 않을까". 자동차 부품은 완제품 코드가 곧 고객 도면 품번인 일이 많아(고객마다 다르고, 설계 변경 때 고객이 바꾼다) **내부 키(시스템 코드)** 와 **바깥 이름(ERP·고객 품번)** 을 나눈다. 바깥 이름은 이미 있는 `mst_ext_id_map`(2장 "외부 키" 행, docs/22) 에 둔다 — 업무 테이블에 ERP·고객 칸을 늘리지 않는다.

### 9.1 고친 결함

`ERP_ITEM_SYNC_MODE` 가 PULL 이 아니면 **이미 쓰는 품목도 수정에서 `item_cd` 를 바꿀 수 있었다**(`ItemMapper.xml` update 의 `set item_cd`). 라벨·LOT·ERP 송신·성적서에 찍힌 코드와 화면 코드가 **조용히** 달라진다(LOT·원장은 `item_id` 로 이어져 있어 오류도 안 난다). → 9.2 (b).
