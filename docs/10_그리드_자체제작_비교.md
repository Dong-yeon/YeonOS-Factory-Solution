## 0. 요약

**결론**: **범용 그리드(셀 편집·범위 붙여넣기·가상 스크롤·고정 열·다단 헤더를 모두 갖춘 것)를 직접 만드는 것은 1인 개발 일정에서 무리다.** 그러나 **조회 전용 그리드는 직접 만드는 편이 오히려 낫다** — 09 에서 본 고객사 문제의 대부분이 조회 그리드 쪽(높이·복사 코드·상태 저장)이었고, 화면의 대부분이 "조회 그리드 + 상세 폼" 구조이기 때문이다.

**추천 = 단계적 결정 (선택지 B→C 판단)**
1. **P0 8단계: 조회 그리드 `hb.grid`(view 모드)를 직접 만든다** — 약 3~5주. 09 의 API·서버 엑셀·저장 규약·상태 테이블은 라이브러리와 무관하므로 그대로 쓴다.
2. **Kendo 구매는 미룬다.** 같은 기간에 1주 PoC(8장): **Tabulator(MIT)** 편집 그리드 + 오픈소스/네이티브 위젯을 **현행 CSP 그대로** 걸고 한글 입력·성능을 실측한다.
3. **P1 시작 전(편집 그리드가 처음 필요한 BOM·단가 화면 전) 결정**: PoC 통과 → **C(Kendo 없음)**, 실패 → **B(편집 그리드·위젯만 Kendo 구매)**.

## 1. 무엇이 어렵고 무엇이 쉬운가

### 1.1 직접 만들기 어려운 것 (편집 그리드의 영역)

| 기능 | 어려운 이유 | 근거 |
|---|---|---|
| **셀 편집 + 한글 IME** | `isComposing` 만으로 부족 — 첫 글자는 compositionstart 가 keydown 보다 늦고, 마지막 글자는 compositionend 가 먼저 와서 **keyCode 229 도 함께 봐야** 한다. macOS Chrome 은 Enter 한 번에 keydown 2회(229, 13), Windows MS IME 는 229 만 오는 경우, iOS 한국어 키보드는 composition 이벤트 자체가 없음, 한/영 전환으로 compositionend 누락 | MDN keydown [원문 R1], [검색 R2·R3·R4] |
| **"입력하면 바로 편집"** | keydown 에서 받은 글자를 에디터에 복사하면 첫 글자가 영문으로 들어감("dㅇㅇ") — **AG Grid #13570(2026-04, 일정 없음)**, Handsontable #4662, CKEditor #748 이 같은 버그. 해법은 셀 선택 중 숨긴 input 에 미리 포커스 | [검색 R5·R6·R7] |
| 키보드 내비게이션 | APG grid 패턴: 탭 순서 1개, 화살표·Home/End·Ctrl+Home/End·PageUp/Down, Enter/F2 편집 진입, Esc 되돌리기, Shift+화살표 범위, 가상 스크롤이면 `aria-rowcount/rowindex` | APG [원문 R8] |
| 범위 선택·붙여넣기 | 엑셀 TSV(따옴표 안 줄바꿈), 타입 파서, 실행 취소, 편집 불가 셀 처리 | [09 5.3] |
| 가상 스크롤 + 고정 열 + 다단 헤더 동시 | 행 높이 동기화·스크롤 정렬. Kendo 도 locked + 많은 행에서 느려짐 | [09 2장] |

### 1.2 직접 만들어도 되는 것 (조회 그리드의 영역)

- 행 수가 서버 페이징으로 **한 화면 50~200행** → 가상 스크롤 불필요(Kendo 공식 문서도 "페이징·가상화 없이 100행 넘게 렌더하지 말라" — 우리는 페이징으로 해결) [09 K17].
- 헤더 고정·첫 열 고정 = CSS `position: sticky`(전역 지원 97%) [원문 R9]. 주의: 가장 가까운 스크롤 조상 기준이라 중간 래퍼의 `overflow` 를 조심.
- 셀 편집이 없으므로 **IME 문제가 없다**(검색 조건 입력란은 일반 input).
- 위치·폭은 `el.style.width = …`(CSSOM)로만 → **`style-src 'self'` 그대로 통과**(CSSOM 대입은 CSP 대상 아님) [원문 R10]. Kendo 의 style-src 미확인 문제(09 3.2)가 사라진다.

### 3.1 자체 조회 그리드의 규칙 (추가분)

- **DOM 생성은 `document.createElement` + `textContent`**(innerHTML 금지 — 현행 가드 그대로). 셀 렌더러가 필요하면 "DOM 노드를 반환하는 함수"만.
- 스타일은 클래스 + CSSOM(`style.width`, `style.left`, `style.transform`)만. `setAttribute('style')`·`style.cssText` 금지(`cssText` 는 브라우저·문서별 해석이 엇갈려 실측 대상) [검색 R10].
- ARIA: `role="grid"`, `aria-rowcount`(서버 total), `aria-rowindex`(페이지 오프셋 반영), `aria-sort`, `aria-selected`, `aria-readonly="true"` [원문 R8]. 셀 포커스는 roving tabindex.
- 1천 행 넘는 클라이언트 모드는 만들지 않는다(서버 페이징 강제) — 가상 스크롤이 필요해지는 순간이 "자체 제작 범위를 넘는 신호".

**Tabulator 를 쓸 때의 규칙** [추정]
- `hb.grid` 의 `mode:'edit'` 내부 구현으로만 사용(화면은 Tabulator API 를 직접 부르지 않음 — 09 4.1 원칙 그대로) → 나중에 Kendo 로 바꿔도 화면 무수정.
- 문자열 HTML formatter 금지(XSS 이슈 #4168) — formatter 는 DOM 노드 반환 함수만 [검색 R19].
- 텍스트·숫자 editor 는 **hb 커스텀 editor**: `keydown` 에서 `e.isComposing || e.keyCode === 229` 면 무시, `compositionend` 이후 Enter 로만 확정, blur 시 확정.
- XLSX 내보내기 기능(SheetJS 필요)은 **쓰지 않는다** — 엑셀은 서버 생성(09 6장). 혹시 쓰게 되면 npm `xlsx` 0.18.5(CVE 2건, 2022 정지)가 아니라 공식 cdn.sheetjs.com 0.20.3 을 vendoring + 체크섬 [원문·검색 R20].
- vendor 파일(`tabulator.min.js`·css)은 MIT 이므로 **저장소 커밋 가능**(Kendo 와 달리). `static/vendor/tabulator/{버전}/` + 라이선스 고지 + SHA-256 기록(05 공급망 — Gradle 체크섬 대상이 아니므로 별도 목록) [추정].

### 11.2 무료 Kendo UI Core 로 되는 것·안 되는 것 [원문·검색 2026-10-15]

- Kendo UI Core 는 Apache-2.0 무료 배포판(npm `kendo-ui-core` 2026.3.812)이고, **Grid·TreeList·Upload·TreeView·Editor·Switch·DateRangePicker·차트는 포함되지 않는다**. 지원(기술 지원)도 없다.
- 포함: DatePicker·DateTimePicker·TimePicker·DateInput, ComboBox·DropDownList·MultiSelect·AutoComplete, NumericTextBox·MaskedTextBox·TextBox, Button·Menu·TabStrip·PanelBar·ToolBar·ListView·Pager·Validator, DataSource. (Window·Splitter·Tooltip 은 최신 포함 여부를 PoC 때 패키지로 확인)
- 라이선스 키는 상용 `@progress/kendo-ui` 배포판에만 요구되는 것으로 보이며 Core 는 불필요로 판단 [추정 — 공식 문구로 명시 확인은 PoC 때].
- CSP: Core 도 같은 템플릿 엔진이므로 **함수 템플릿만**(G7), `style-src` 는 PoC 실측.
- 장점: 나중에 상용으로 올려도 같은 API·테마(편집 그리드만 추가하면 됨). 단점: jQuery 의존, 지원 없음, 한글 IME 동작 미확인.

### A.3 정리

- 우리 CSP(`script-src 'self'; style-src 'self'`)를 그대로 둘 수 있는 무료 편집 그리드는 **Tabulator 가 사실상 유일**하다. SlickGrid·AG Grid·RevoGrid·TOAST UI 는 `<style>` 을 동적으로 넣어 요청마다 nonce 를 붙이는 CSP 구조가 필요하다(01 7장 개정 사안).
- **한글 IME 를 제대로 처리한 무료 그리드는 찾지 못했다** — 어느 것을 쓰든 hb 공통 IME 헬퍼와 8장 2일차 시나리오가 필요하다.
- 유료로 갈 경우 Kendo 외 비교 대상은 **IBSheet(국산·한글 강점, 도메인 라이선스 비용 구조 확인)** 와 **Syncfusion(커뮤니티 라이선스로 초기 0원, SaaS·재배포 조건 서면 확인)** — 8.1.

- 파일은 저장소에 넣지 않는다(재배포 조건 불명확): `scripts/` 내려받기(버전 고정·SHA-256) + gitignore `vendor-local/highcharts/`. 없으면 `hb.chart` 가 설치 안내를 그린다.
- 참고: ApexCharts 는 5.0 부터 MIT 가 아니고(8.x Community = 연 매출 200만 달러 미만 무료, 남이 쓰는 제품·플랫폼에 넣으면 OEM 유료), 무료(상업 포함) 대안은 Apache ECharts·Chart.js·uPlot·billboard.js(docs/61 5.0).
