## 4. 바로 할 만한 것 (작고 근거가 분명한 순)

1. **S1 RLS + LIKE 실측** — P1 조회 화면이 이미 있어 지금 검증 가능. 큰 회사 시드(수십만 행) + 앱 계정 `EXPLAIN (ANALYZE)` 로 품목·BOM 검색. 결과에 따라 새 V 파일.
2. **S2·S11 "하지 않는 것" 기록** — 00 에 TimescaleDB·GraalVM 네이티브를 근거와 함께. P2 원장 설계(파티션 + BRIN) 전에.
3. **U13 IME 테스트 항목 + U3 closedby 규칙** — 16·TESTING 체크리스트 보강만.
4. **S5 SSRF 항목** — 05 에 추가, 아웃박스 HTTP 클라이언트 단일화는 ERP 어댑터(P6) 때.
5. **M4 회사 데이터 반출 명세** — 05 의 "회사 데이터 내보내기" 를 기능 명세로(구현은 SaaS 공개 전).

P2 착수 전에 정할 것: U1(팝업 엔진), U10(카메라 스캔 CSP), S2(측정값 원장 저장 방식), M2(MCP 앞당길지).
